**Context:** ADR 0021 s5 and ADR 0024. TC-021 declared the list-template operation and
routes every reactive list Static as `not yet emittable`. This task makes it real.

**Do:**

- The initial items reuse TC-021's loop operation verbatim. Its source is the seed arg,
  and the key and raw sources are item-scope holes.
- The list-template operation: the inert item shape, with no holes and client-written
  sites empty, one shape for all items. It is stamped `data-list="N"` and placed as a
  direct child of the host in document order, whatever the nesting depth. This is the
  same placement SSG uses today, so the output stays byte identity.
- Extend the loop-source grammar so that a source may be a member path over an enclosing
  item scope. Nested lists then nest as native loops.
- The dump target's interpreter implements nested loop scopes.
- Retire `not yet emittable` for reactive lists. A list whose seed is not a server arg
  routes Static as `non-portable initial`.

**Diagnostics:** none new.

**Check:** every corpus component with a reactive list, including a nested one, renders
byte-identically to SSG through the dump target for every fixture × locale. A build with
no target configured is byte-identical.
