**Context:** ADR 0021 s4 (D-28 ruled): a template target executes no driver, so an
async boundary can be emitted only when the task's initial value routes from a server
arg, the **result arg**. TC-021 declared the `boundary` operation and routes every async
boundary Static as `not yet emittable`. This task makes the operation real. The target
stays internal (iteration-3 ruling, 2026-10-11, recorded on TC-021).

**Do:**

- The walk emits the boundary operation. It carries the `ok`/`nil`/`err` arms, the
  three-state result test (`T` → `ok`, `{ error: { code, message } }` → `err`, null →
  `nil`) and the err scope: the catch parameter's reads become member paths over the
  shape's `error`. The arms that do not win stand beside the winner as inert arm
  templates, using the same server-hole / empty-client-site rule as conditionals.
- Routing (census rows, not warnings): a task whose initial value comes from an opaque
  driver routes Static as `non-portable initial`. A result shape the walk cannot decide
  routes Static as `ambiguous result shape`. Retire `not yet emittable` for boundaries.
- The dump target's interpreter implements the result test.
- A **boundary fixture component** under `examples/`: a task seeded from a result arg,
  with all three arms. No corpus component uses `Try` yet (the consequence note in
  ADR 0019). Its goldens are new and intentional, so they are reviewed, not regenerated
  to pass. It is offered to the Le Truc corpus at that repository's cutover.

**New diagnostic** (compiler channel, tier 1 Prevented, emitted only when a template
target is configured): LTC090, a boundary result type that has its own `error` member.
The three-state test is ambiguous for it. The fix is to rename the field. The code is
reserved for this task. The copy follows `writer` → error-messages.

**Check:** the fixture renders byte-identically to SSG through the dump target, in all
three arm states × every locale. LTC090 fires on a fixture with an `error` member and on
nothing else. A build with no target configured is unchanged apart from the fixture's
own new SSG output.
